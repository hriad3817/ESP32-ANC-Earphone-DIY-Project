# ESP32-S3 ANC Earphone / MP3 Player Project

A custom hardware schematic for an ESP32-S3 based portable audio player featuring I2S audio output, SPI display support, and SD card storage.

## Hardware Components
- **MCU**: ESP32-S3-WROOM-1
- **Audio DAC**: PCM5102A (I2S)
- **Display**: SPI TFT Display
- **Storage**: MicroSD Card Slot (SDIO)

## Project Files
- `schematic.kicad_sch`: Primary KiCad 6+ schematic file.
